RELION numerical reference attribution
=====================================

Greco contains Python ports of identified RELION numerical routines and
postprocessing. The minimal C++ core calls FFTW/glibc directly and retains
reference FFT normalization and FSC/Guinier accumulation conventions.

Original notices for those reference routines are retained below.
The GPL text is in COPYING.txt.
